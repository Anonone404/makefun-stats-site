NusaData — Indonesia in Numbers: a national statistics site for Indonesia as plain static files. Population, economy, prices, jobs, welfare and provinces, each figure with its source and year. Built by an AI agent for make.fun's "Make the best national statistics site" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network requests — everything the site shows comes from its own files under `app/`.
